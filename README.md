# SKYGRID

정찰 임무 연속성 확보를 위한 군집 무인기 운용·검증 웹 앱이다. DJI Mavic Pro와 DJI Avata 2를 사용하는 2기 현장 실험, 비행 후 로그 검증, 다수 무인기 가상 실험을 하나의 공통작전상황도에서 수행한다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 연다. 배포용 검사는 `npm run build`로 수행한다.

## GitHub Pages 배포

`main` 브랜치에 푸시하면 `.github/workflows/deploy-pages.yml`이 정적 사이트를 빌드해 GitHub Pages에 자동 배포한다. 프로젝트 저장소의 Pages 설정에서 배포 소스를 **GitHub Actions**로 지정해야 한다. 저장소 이름은 빌드 시 자동으로 감지되므로 `https://사용자명.github.io/저장소명/` 경로에서도 정적 자산이 정상적으로 로드된다.

## 주요 운용 모드

1. **현장 운용**: 지도에 기지와 정찰지점을 지정하고 DJI Mavic Pro·DJI Avata 2를 배치하면 현재 학습 정책이 모든 지점을 기체별 경로로 배정한다. Mavic Pro 경로는 기지 출발·정찰·기지 복귀가 포함된 Litchi Mission Hub CSV로 내려받고, Avata 2 경로는 지도와 조종 유도 CSV로 확인한다. 기체 이탈을 보고하면 잔여 기체에 미완료 지점을 다시 배정한다. 이 모드는 DJI 기체를 직접 조종하지 않으며 운용자의 상황 입력과 의사결정을 지원한다.
2. **비행 검증**: AirData 등에서 내보낸 DJI CSV 로그를 한 개 이상 불러와 비행거리, 속도, 고도, 배터리 소모율, 계획경로 추종오차와 2기 간 공백 회복시간을 계산한다. 여러 로그는 경과시간 기준으로 정렬해 지도에 중첩한다.
3. **가상 실험**: 기체 수, 정찰지점 수, 기체 이탈 시점, 임무시간, 실험 배속과 재계획 알고리즘을 바꾸어 임무를 반복한다.
4. **성능 비교**: 최근접 우선, 중요도 우선, 강화학습 정책을 같은 무작위 시나리오에서 반복 비교한다.
5. **AI 학습**: 현재 지도 구성을 변형한 시나리오와 일반화 시나리오로 새 정책을 학습하고, 미사용 시나리오 검증을 통과한 모델만 저장한다.

## 실제로 동작하는 알고리즘

- **제약 인지 잔차 DQN**: 기체–정찰지점 후보마다 20개 특성을 입력받는 `20-48-1` 후보가치 신경망이다. 경험 재현, 목표 신경망, ε-greedy 탐색과 TD 학습을 사용한다. 기본 모델은 16,000개 시나리오로 학습했다.
- **상태·행동 특성**: 이동·복귀거리, 정찰 중요도, 긴급도, 재방문 여유, 기체·편대 배터리, 예상 에너지 소모, 복귀 예비량, 상대적 거리 이점, 주변 지점 밀도, 기체별 누적 업무량 등을 사용한다.
- **제약 조건**: 잔여 배터리가 기체별 복귀 예비량보다 낮아지는 행동은 후보에서 제외한다.
- **경로 후처리**: DQN이 선택한 첫 긴급 지점은 유지하고, 같은 기체에 배정된 후속 지점은 2-opt로 정리해 불필요한 우회를 줄인다.
- **A\* 경로탐색**: 직선 경로가 비행 제한구역과 겹치면 격자 기반 A\*로 우회 경로를 계산한다.
- **평가지표**: 중요도 가중 정찰 연속성, 중요도 가중 정찰 공백, 임무 완료율, 총 비행거리, 방문 횟수, 평균 배터리를 계산한다.

## CSV 입력

위도와 경도 열은 필수다. 다음과 같은 열 이름을 자동 인식한다.

- 시간: `time(ms)`, `time(sec)`, `elapsed_time`, `datetime`
- 위치: `latitude`, `longitude`
- 비행상태: `altitude`, `speed`, `vertical_speed`, `heading`, `flight_mode`
- 기체상태: `battery_percent`, `satellites`

테스트 파일은 `public/samples/skygrid_sample_log.csv`에 있다. 원본 DJI 비행기록은 AirData의 CSV 내보내기를 권장한다.

## 주요 코드

- `components/skygrid/skygrid-app.tsx`: 운용 화면과 세 모드의 상태 관리
- `components/skygrid/operational-map.tsx`: 지도, 경로, 제한구역, 로그 중첩
- `lib/skygrid/rl-policy.ts`: DQN 훈련·추론과 다중 기체 임무 할당
- `lib/skygrid/pathfinding.ts`: A\* 우회 경로
- `lib/skygrid/simulation.ts`: 이산시간 임무 시뮬레이션과 반복 비교
- `lib/skygrid/log-parser.ts`: DJI CSV 파싱과 실비행 지표 산출

## 실험 해석 시 주의사항

웹 앱의 DQN은 연구용 경량 정책이며 실제 기체의 비행제어기를 대체하지 않는다. 현장에서는 조종자가 안전과 항공법을 우선하고, 앱이 제시한 경로를 참고해 각 DJI 조종 앱에서 임무를 수행한다. 논문에는 시뮬레이션 설정, 난수 시드, 정책 학습 에피소드, 로그 추출 방식과 실패 판정 기준을 함께 기록해야 재현할 수 있다.

기본 모델의 외부 검증은 학습·튜닝에 사용하지 않은 3개 난수 묶음, 총 480개의 30분 임무로 수행했다. 평균 연속성은 DQN 40.88%, 최근접 우선 40.32%, 재방문 기한 준수율은 각각 48.70%, 47.82%, 이탈구역 회복 성공률은 각각 96.67%, 79.38%였다. 이 수치는 현재 모의환경에 대한 결과이며 실기체 성능을 의미하지 않는다.
